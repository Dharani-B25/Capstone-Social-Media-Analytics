# Capstone: Social-Media-Analytics

An in-depth analysis of 2013 social media messages (tweets and Facebook posts) generated by United States politicians over a two-day span.

---

### Project Overview

This capstone project is divided into two primary phases, transforming raw social media text into actionable comparative insights:

#### Phase 1: Data Parsing & Enrichment

* **Data Organization:** Restructured the original CSV dataset to streamline the analytical stages.
* **Feature Engineering:** Parsed the raw text and labels to append critical new columns to the dataframe.
* **Extracted Metadata:** Successfully isolated and added data points for the politician's name, location, position, message sentiment, and hashtag usage.

#### Phase 2: Deep-Dive Analysis

* **Targeted Filtering:** Segmented the data based on specific poster information to isolate trends.
* **Sentiment Comparison:** Analyzed the positive and negative sentiments surrounding various topics to compare different politicians.
* **Hashtag Metrics:** Explored the most popular hashtags across the dataset and calculated their average sentiment scores.
